# La Mutina website

Prima versione dimostrativa del sito La Mutina.

## Pubblicazione con GitHub Pages

1. Caricare tutti i file nella cartella principale del repository.
2. Aprire Settings > Pages.
3. In Build and deployment scegliere:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
4. Salvare.

Il sito sarà pubblicato all'indirizzo GitHub Pages indicato da GitHub.
