LA MUTINA — SITO STATICO PER GITHUB PAGES

STRUTTURA
- index.html: homepage
- prodotti.html: panoramica della collezione
- easy.html, premium.html, custom.html: pagine prodotto
- chi-siamo.html: storia, materiali e sostenibilità
- contatti.html: modulo contatti
- style.css: grafica e versione mobile
- script.js: menu mobile e modulo email
- assets/: immagini del sito

CARICAMENTO SU GITHUB
1. Apri il repository destinato al sito.
2. Elimina o sostituisci i vecchi file del sito.
3. Carica TUTTO il contenuto di questa cartella nella root del repository, mantenendo la cartella assets.
4. Apri Settings > Pages.
5. In Build and deployment scegli Deploy from a branch.
6. Seleziona la branch main e la cartella / (root), quindi salva.
7. Attendi qualche minuto e aggiorna il sito.

Il file iniziale è index.html.
Il modulo Contatti apre il programma di posta dell’utente e non salva dati.
