LA MUTINA — SITO STATICO PER GITHUB PAGES

1. Carica nella root del repository tutti i file e la cartella assets.
2. In GitHub apri Settings > Pages.
3. Seleziona Deploy from a branch, branch main, cartella / (root).
4. Il file iniziale è index.html.

Il modulo Contatti apre il programma di posta dell’utente e non richiede server.
