LA MUTINA — SITO STATICO PER GITHUB PAGES

VERSIONE: homepage con fotografia ESTATE / INVERNO

1. Estrai lo ZIP.
2. Carica nella root del repository tutti i file HTML, style.css, script.js, README.txt e la cartella assets completa.
3. Non estrarre le immagini dalla cartella assets e non rinominare la cartella.
4. In GitHub apri Settings > Pages.
5. Seleziona Deploy from a branch, branch main, cartella / (root).
6. Il file iniziale è index.html.

Il modulo Contatti apre il programma di posta dell’utente e non richiede server.
